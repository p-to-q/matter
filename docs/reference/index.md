# Reference

These are implementation notes for non-obvious local problems. They provide
context, not repository law. Read the relevant note when entering that problem;
ordinary component and store work needs no matching document. A note marked
*historical* or *partly superseded* is decision trace: read it for why, and
take the current rule from the note it names.

A note marked **binding** holds exact rules that a contract document
(`product.md`, `principles.md`, `material.md`, `architecture.md`,
`protocol.md`) hands to it by link, such as Wiki's evidence and occurrence
policy, the undo bound, the index structure grammar, or the corner optical
geometry. Those rules carry the contract's authority, so changing one is a
contract change and a form-changing one is recorded in
[`../changes.md`](../changes.md). The rest of a binding note is still context.
Keeping these rules beside their mechanics avoids a second, drifting copy in
the contract documents.

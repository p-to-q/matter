# Reference

These are implementation notes for non-obvious local problems. They provide
context, not repository law. Read the relevant note when entering that problem;
ordinary component and store work needs no matching document.

| Note | Useful when working on |
| --- | --- |
| [`foundation.md`](foundation.md) | choosing a base, module ownership, or a dependency |
| [`text-material.md`](text-material.md) | punctuation segmentation and lasso geometry |
| [`tree-layout.md`](tree-layout.md) | variable-height rooted layout |
| [`tool-system.md`](tool-system.md) | contextual tool projection and rail behavior |
| [`history-and-undo.md`](history-and-undo.md) | atomic tree commands and exact inverse |
| [`voice-input.md`](voice-input.md) | microphone and transcription lifecycle |
| [`agent-boundary.md`](agent-boundary.md) | model authority and provider boundary |
| [`virtual-file-system.md`](virtual-file-system.md) | Markdown snapshot and browser durability |

Add or revise a note only when a choice will matter to later implementation, or
when introducing a dependency. A short statement of the need, useful prior art,
current choice, and important rejected path is enough.

# Source Ledger

Matter is independently implemented. Sources inform product direction, visual
language, repository discipline, and provider adapters.

| Source | Used for | Adaptation |
| --- | --- | --- |
| `ptoq-arrow-blueprint.zip` | thesis, interaction grammar, protocol boundary, demo scope | Revised for a standalone repository and split public actions from private reversible mutations. |
| [p-to-q/repo-template engineering discipline](https://github.com/p-to-q/repo-template/blob/main/docs/engineering-discipline.md) | repository-first change discipline | Adapted into `docs/engineering-discipline.md` with Matter boundaries and demo gates. |
| [ptoq.io](https://www.ptoq.io/) | muted field, charcoal text, mono restraint | Canvas interpretation; the immersive UI does not copy the article layout. |
| [GC Minimal Zine Poster](https://github.com/LiamGvchi/gc-minimal-zine-poster) | matte scanned paper, fine fibers, aged mottling, and restrained print defects | Adapted as a deterministic monochrome SVG texture. Poster composition, imagery, and accent-color rules were not copied. Source repository is MIT licensed. |
| [OpenAI file transcription](https://developers.openai.com/api/docs/guides/speech-to-text) | recorded audio endpoint and model boundary | Optional server adapter; mock remains default. |
| [OpenAI structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs) | schema-constrained planning response | The response is converted to Matter's own validated `ActionPlan`. |

External source content does not override repository product or architecture
invariants.

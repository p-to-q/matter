# Soft Input — 黑客松研究命题与 Demo 说明

## 一句话

**当 AI 已经能够推断意图，界面能否少要求一点“准确描述”，多容纳一点人的表达？**

Soft Input 不是 AI 白板，也不是 prompt builder。当前 MVP 只验证一个最小命题：**文字是否可以成为一种能够被指向、圈选和捏开的材料。** Agent 藏在 Scale 动作背后，根据用户拉开的尺度补全不同长度的语言，而不是占据屏幕中央聊天。

## 当前 MVP：Scale / Text

画面只保留一段大文字。中间的语句被一个半透明区域圈选，左右两个触点控制它的尺度：

- 向外拉，圈选区域变宽，AI 逐步生成更长、更完整的中间语句。
- 向内收，内容重新压缩，只保留句子的核心意图。
- 右侧三个轻量控制决定 expansion 的方向：Wander、Precise、Stranger。
- 桌面端可拖动任意一侧的触点；触屏端支持真实双指 pinch。

这不是“改变字号”，而是用空间尺度控制语义展开程度。页面刻意不再显示导航栏、画布工具、prompt 输入框或其他研究实验，让体验第一眼就能被理解和尝试。

## 三条路线

1. **单一魔法手势**：把“捏合文字”做到极高完成度。最适合 30 秒传播视频，但研究边界窄。
2. **意图游乐场（当前选择）**：三种实验共享同一套语法，既有可玩的 hero interaction，也能表达完整命题。
3. **生成式 AI 操作系统**：任何圈选、连接、手势都动态生成合适 UI。愿景最大，但黑客松现场容易变成半成品框架。

## 引擎后续可以扩展的交互

### 01 Scale a sentence（当前已实现）

向外拉橙色触点，AI 不是简单增加字数，而是逐步恢复一句话中被压缩的犹豫、限定和态度。它把“输出长度”重新解释成“允许多少意图被展开”。

### 02 Give it a direction

在二维语义场中拖动触点：横轴从 obey 到 provoke，纵轴从 strange 到 precise。用户用方向而不是标签表达 taste，agent 决定对应的语言形式。

### 03 Follow a thought

点击一个词，空间中长出它的邻近概念；继续点击就继续推理。这里没有对话轮次，推理是一片可以游走的地形。

底部输入框允许用户放下一段自己的“未完成想法”，系统不会立刻给答案，而是把它拆成一张仍可继续生长的纸条。

## 设计语言

- **底色**：冷白 `#F7F7F4`，避免典型 AI 产品的暖米色。
- **正文**：墨黑 `#191917`；静默层级用灰，不用大量边框。
- **意图色**：陶土橙 `#EF6848` 是手指触点和 agent 感知状态；靛紫 `#4B3CA7` 表示被展开的隐含语义；蓝 `#2D5BD1` 表示空间推理。
- **字体**：Bricolage Grotesque 负责界面与正文，Azeret Mono 负责研究标注；斜体只在命题里出现。
- **结构**：不是 dashboard，而是带作品编号、实验标记和可拖动物件的研究工作台。

## 技术框架判断

- **当前 demo：自定义 React + Pointer Events**。原因是核心是三个高度定制的身体化交互；自己控制手势和视觉，体积小、现场最稳。
- **需要真正无限画布、多人、撤销历史时：tldraw SDK**。它已经提供画布、shape/tool/UI 自定义、持久化和同步；非常适合第二阶段把每个实验变成 custom shape。
- **如果产品转向“节点工作流”：React Flow**。它适合明确的 node/edge 编辑器，但会把体验天然推向流程图，不适合当前更暧昧的艺术研究。
- **动效升级：Motion**。适合手势惯性、布局过渡和生成反馈；当前原型用 CSS 和 Pointer Events 保证最少依赖。
- **无样式组件：Base UI 或 Radix Primitives**。适合后续补齐 popover、tooltip、dialog 和可访问性，同时不强加视觉。

## 现场讲述结构（90 秒）

1. **问题（15 秒）**：AI 越来越会理解人，但我们仍然被要求把想法压成一个准确 prompt。
2. **命题（10 秒）**：如果 AI 能推断，界面能不能像人与人交流一样，理解动作、方向和犹豫？
3. **玩三个实验（50 秒）**：先捏开一句话，再用语义场把它推向 strange / precise，最后沿某个词继续生长。
4. **结尾（15 秒）**：我们没有设计一个更好的输入框；我们在尝试一种允许人不完整地表达、让机器负责靠近的界面。

## 可继续拓宽的边界

- 把声音的停顿、重音和语速也作为“形状”，而不只是转写成文本。
- 两个人在同一画布上留下不同方向，agent 只展示冲突和重叠，不替他们做决定。
- 让 agent 拥有 taste，但同时显示它删掉了什么、为何拒绝生成某些形式。
- 把推理保存为可回放的空间路径，而不是聊天记录。
- 支持手机双指真实 pinch；桌面端保留双触点拖动。

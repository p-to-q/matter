# Agent task prompt

```text
Work on Matter as a careful repository maintainer.

Read README.md, docs/engineering-discipline.md, the relevant code/tests, and any
related ADR or active plan before editing.

For the task:
1. name the user-visible claim and smallest affected boundary;
2. state constraints, preserved behavior, validation, and non-goals;
3. implement the smallest coherent change;
4. add focused behavioral tests;
5. run exact relevant checks;
6. report files, evidence, risks, and deferred work.

Do not add a parallel architecture, speculative abstraction, provider call in a
component, detached chat UI, keyboard-dependent primary path, or generative
mutation without exact undo.
```

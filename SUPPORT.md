# Support

Matter is proprietary software under active development, published here without
a public support commitment. See [`LICENSE`](LICENSE).

There is no public support channel. Issues and feature proposals from outside
Wooden Computer Co., Ltd. are not triaged and may be closed without reply.

Security or privacy concerns are the exception: report them privately through
`SECURITY.md`, never in a public issue.

Internally, a bug report carries browser, route, reproduction steps, and whether
fixture mode reproduces the problem. A feature proposal carries the interaction
claim, human input channels, direct material consequence, and undo path.

The current application is experimental. Unsupported surfaces are listed in
`docs/surfaces.md`.
